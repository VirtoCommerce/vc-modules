## Breaking changes

1. **`ConfiguredLineItemContainer` — section-line-item overloads replaced.** The string-argument creation overloads were removed in favor of `ProductConfigurationSection`-based ones:
   - `AddProductSectionLineItem(CartProduct, int quantity, string sectionId, string type)` and `AddProductSectionLineItem(CartProduct, int quantity, bool selectedForCheckout, string sectionId, string type)` → `AddProductSectionLineItem(CartProduct, ProductConfigurationSection)`.
   - `AddTextSectionLineItem(string customText, string sectionId)` → `AddTextSectionLineItem(ProductConfigurationSection)`.
   - `AddFileSectionLineItem(IList files, string sectionId)` → `AddFileSectionLineItem(ProductConfigurationSection, IList)`.

   Code that builds a container by hand must pass the `ProductConfigurationSection` (carrying `SectionId` / `SectionName` / `Type` / `Option`) instead of the loose string arguments.

2. **`ConfiguredLineItemContainer.CreateSectionLineItem(string sectionId, string type)` removed.** Replaced by a parameterless `CreateSectionLineItem()` plus `CreateSectionLineItem(ConfigurationItem)` / `CreateSectionLineItem(ProductConfigurationSection)` overloads. Subclasses that overrode the string-based factory must move to the new overloads.

3. **`ConfiguredLineItemContainer.ProductsIncludeFields` removed.** The property no longer exists. Remove any reads or writes of it; product field-selection for configured items is resolved on the load path, not on the container.

4. **`CartAggregate` — `protected virtual` extension points changed.** Subclasses overriding these must update their signatures:
   - `ApplyConfigurationSectionAsync(...)`: return type `Task` → `Task`; the `IDictionary products` parameter was removed (products are read from `CartProducts`).
   - `CreateConfigurationItem(ProductConfigurationSection)` → `CreateConfigurationItem(ProductConfigurationSection, CartProduct)`.
   - `CreateConfiguredLineItemContainer(LineItem, IDictionary)` → `CreateConfiguredLineItemContainer(LineItem)`.
   - `GetOrCreateConfigurationItem(LineItem, ProductConfigurationSection)` → `GetOrCreateConfigurationItem(LineItem, ProductConfigurationSection, CartProduct)` (new optional parameter; overrides must match the new signature).
